# Cybertron v0.3.0

> 发布状态：待发布；本文件用于 v0.3.0 GitHub Release。
> 上一版：[v0.2.1](https://github.com/zhiwenC125/Cybertron-agents/releases/tag/v0.2.1)

## 0.3 定位

0.3 是 v6 动态任务图的功能版本。运行时从固定九步账本改为“prima 提议、内核裁决”：prima 通过 `cy_plan` 提交节点与依赖，内核校验能力、角色、`write_scope` 和计划版本，按实际 diff 计算风险下限；模型不能删除下限内的门禁，也不能用文字代替工具回执。

## 变更

### 计划与执行（M0–M2）

- 图计划 schema v2、单节点计划、写范围守卫；越界写入由 `scope_guard` 自动回滚。
- 测试门四种结论：`pass`、`fail`、`not_applicable`、`waived`；`waived` 只能由用户回执产生。
- 风险门禁按实际 diff 计算（文档 / 代码 / 公共接口 / 固件 / 设备），只能加不能减。
- `cy_check` 在隔离运行器中执行固定 lint/build/test/sim 目标；覆盖 python、node、cmake-arm 等配置档，真实 `clang-tidy` 与 CMake 回执入账。
- 角色目录 `registry.py` 增加能力、写根上限和 `assert_catalog()` 不变量；OpenCode 配置由导出器生成。

### 并发、修复与设备（M3–M4）

- 按 `write_scope` 上锁的并发派发；每个派发独立快照与宿主权限绑定。
- Loop-1 节点修复、失败指纹去重、L2 拒绝后的受影响子图局部返工。
- 设备操作审批绑定设备、固件哈希、擦写范围和回滚镜像；单次使用，结果不明记 `outcome_unknown` 且不自动重试。
- Renode 仿真配置档；STM32 真机完成烧录、SRAM 心跳和 64 KiB 逐字节回滚。

### 学习与第二宿主（M5）

- 完成运行沉淀为模板；复用必须重新通过 `PlanGraph` 校验。`skip` 只能跳过只读分析节点并重接依赖。
- `cy_metrics` / `cybertron.metrics` 从事件账本生成指标面板与两次运行对比。
- 真实 OpenCode 宿主上，同类需求第二次运行节点数 2→1、人工干预 1→0。
- 随包分发实验性 DSH 适配器；`Cybertron v6` preset 只挂载 `cy_*` 工具，经同一 Python 内核记账。

## 安装

**npm**

```bash
npx -y cybertron-agents@0.3.0 init --apply --global
```

**pipx**

```bash
pipx install cybertron-agents==0.3.0
cybertron init --apply --global
```

**GitHub Shell**

```bash
curl -fsSL https://raw.githubusercontent.com/zhiwenC125/Cybertron-agents/v0.3.0/install.sh -o install.sh
bash install.sh --apply --global --version v0.3.0
```

DSH：

```bash
dsh plugin --profile desktop add "$(cybertron dsh path)"
```

## 升级说明

- 旧的九步 run 只读保留，可继续 `verify` 和导出报告，但不参与 v2 调度；新 run 使用图 schema。
- 角色权限变化后需重新运行 `cybertron init --apply` 并执行 `opencode2 debug agents` 核对。
- 模型编队配置沿用 `cybertron models`，0.3 不改变模型 ID 的存放位置。

## 已知限制

- DSH 适配器是单一 prima persona + `cy_*` 工具，没有把 13 角色映射为 13 个 DSH preset，也没有绑定 DSH 子会话的写范围；定位为实验性第二宿主。
- 飞书 Wiki 写入仍只允许 `alpha-trion` 经受空间约束的网关执行，真实测试只在指定测试空间运行。
- 物理烧录、设备上电和远程部署仍需每次单独审批，绑定具体设备、固件、擦写范围与回滚方案。
- 设备操作结果不明时记 `outcome_unknown` 且不自动重试，需要人工确认。
