# Cybertron Agents 0.7.3

发布日期：2026-11-18

0.7.3 修复一个阻塞问题：一个 OpenCode 会话里完成过 run 之后，再提新任务会失败。插件把 `run/<session>` 一直保留，于是下一次规划派遣被当成节点派遣，报 `Native subagent requires node card, role, and call ID`；prima 只能退回旧 run 的 ready 节点。

## 修复

- 规划和派遣前检查已绑定的 run。若 run 已 `completed`，先清掉会话绑定，再按新任务处理：
  - `cy_plan` 会新建 run，而不是报 `Existing run requires one graph operation`；
  - `subagent` 派遣会走规划者分支，而不是要求节点卡片。
- 只清除 `completed` 的 run；`ready` / `blocked` / `running` 仍然保留，避免打断重试与阻塞恢复。

## 行为变化

- 同一会话可以连续做多个任务，每个任务一个新 run；旧 run 目录仍保留在 `.cybertron/runs/`，只是不再绑定到会话。
- 想接着处理旧 run，用它的 `run_id` 通过 `cy_state` 查看；已完成的 run 不能追加节点。

## 升级

```bash
cybertron init --apply
cybertron doctor --global
# 或
npx -y cybertron-agents@0.7.3 init --apply
```

升级后重启 OpenCode。
