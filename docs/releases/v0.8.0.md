## 主题

0.8.0 把 Cybertron 从“固定流程编排”推进到“意图优先的动态编排”：

- Intent 契约：goal / done / non_goals / forbidden capabilities / paths；
- 完成判定从“节点全绿”改为“每条 done 都有节点绑定的证据”；
- 新任务或契约变化用 `new_run` / supersede，旧 run 保留血缘；
- Grant：按节点请求、人工批准、单次消费、standing 模式；
- 权力矩阵按工具原子重导出；审查者 A 的读 deny-list；Git 归 `vector-prime`；
- full-access 执行拦截器与高危动作确认；
- `cybertron v6 runs/show/grants/lineage` CLI 查询；
- `seed_from_run_id` 只复制计划形状。
