# Cybertron Agents 0.5.1

发布日期：2026-11-18

0.5.1 修复 0.5.0 的 OpenCode 插件安装缺文件问题：`cybertron.js` 会导入 `shell_policy.mjs`，但安装器没有复制该文件，导致新项目加载插件时报 `Plugin failed`。

## 修复

- Python 安装器在复制 `cybertron.js` 与 `hook_logic.mjs` 时，同时复制 `shell_policy.mjs`。
- npm 安装器在 `lib/install.mjs` 中加入同一策略文件。
- `cybertron doctor` 的健康检查会检查 `shell_policy.mjs`；缺失时报告运行时缺失。
- 安装器回归测试覆盖 `shell_policy.mjs` 的落盘与内容一致性。

已在全新临时项目验证：`cybertron init --apply` 后 `.opencode/plugins/` 同时存在 `cybertron.js`、`hook_logic.mjs`、`shell_policy.mjs`，OpenCode 不再报插件加载失败。

## 安装

```bash
# npm
npx -y cybertron-agents@0.5.1 init --apply --project .
npx -y cybertron-agents@0.5.1 models setup

# pipx
pipx install cybertron-agents==0.5.1
pipx ensurepath && exec zsh
cybertron init --apply --project .

# GitHub Shell
curl -fsSL https://github.com/zhiwenC125/Cybertron-agents/releases/download/v0.5.1/install.sh -o install.sh
bash install.sh --apply --project .
```

## 升级说明

- 已经用 0.5.0 初始化过的项目，重新运行 `cybertron init --apply --project .` 即可补上 `shell_policy.mjs`；不需要删除现有配置。
- 升级后重启 OpenCode，让插件与新文件生效。
- 0.5.0 的其它功能不变：十三天规划、prima 派发、`cy_plan_review` 评审门禁与角色 shell 白名单。
