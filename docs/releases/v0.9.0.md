# Cybertron Agents 0.9.0

## OpenCode Harness Loop

- Prima 作为默认入口，接续计划、派发节点和报告回执。Thirteenth 可以通过 Shift+Tab 单独规划，切回 Prima 时继续同一会话和 run。
- 执行反馈可以触发同一 run 的版本修订。已完成的无关节点和有效回执可复用，过期版本和在途冲突由内核拒绝。
- 计划提交时检查任务范围、节点依赖和验证可执行性。精确单文件任务可以由内核回读结算。测试和验收按任务需要绑定真实工具回执。
- 会话横幅显示规划、派发、修订、专项确认和最终交付。项目外单文件写入由 OpenCode 对精确文件请求授权。
- 并行会话的账本与模板独立于业务文件回滚。派单回执绑定到单次调用，拒绝其他派单时不会影响在途节点。静态审查只显示该节点可用的只读工具，隔离执行工具保留给绑定的验证节点。

## 升级

安装新版后重启 OpenCode。日常任务使用默认 Prima，需要先审阅方案时通过 Shift+Tab 选中 Thirteenth。安装说明见 [README](../../README.md)。

## 验收与适用范围

隔离项目验证了单文件交付、回读、同一 run 修订、两种入口接续及外部单文件审批。详见 [结构化验收摘要](../testing/harness-loop-release-validation.json)。

通用设备上电与远程部署的宿主适配仍待接入。实际物理操作继续使用项目专项授权。当前固定隔离检查依赖 macOS 的 `sandbox-exec`。
