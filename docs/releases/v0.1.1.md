# Cybertron v0.1.1

> 已发布：2026-11-14 · npm `cybertron-agents@0.1.1` · PyPI `cybertron-agents 0.1.1`
> 上一版：[v0.1.0](https://github.com/zhiwenC125/Cybertron-agents/releases/tag/v0.1.0)

## 变更

- **许可证元数据修复**：`pyproject.toml` 改用 SPDX 字符串 `license = "MIT"`，并声明 `license-files = ["LICENSE"]`，消除 setuptools 的 `project.license` 弃用警告。
- **新增 LICENSE 文件**：仓库根目录加入 MIT 许可证。
- **`cybertron doctor` 不再联网**：体检只做本地检查（角色数量、命令、配置）；本地没有 payload 时使用内置期望值 `13`，不再每次下载 GitHub 归档。
- **文档更新**：README 与 `docs/packaging-and-installation.md` 补充三条安装路径、发布状态与 `npx` 在仓库目录内运行的注意事项。

本版本是安装与元数据补丁，不改变 13 个角色与 `/cybertron` 命令的内容。

## 安装

**npm**
```bash
npx -y cybertron-agents@0.1.1 init --dry-run
npx -y cybertron-agents@0.1.1 init --apply --project .
```

**pipx**
```bash
pipx install cybertron-agents==0.1.1
cybertron init --dry-run
cybertron init --apply --project .
```

**GitHub Shell**
```bash
curl -fsSL https://raw.githubusercontent.com/zhiwenC125/Cybertron-agents/v0.1.1/install.sh -o install.sh
sh install.sh --dry-run --version v0.1.1
sh install.sh --apply --project . --version v0.1.1
```
