# Cybertron Agents 0.7.0

发布日期：2026-11-18

0.7.0 把 Cybertron 收敛为**单一入口**：人类只和 `prima` 对话。没有计划时，prima 先派 `thirteenth` 作为规划子代理，向人类澄清意图并生成计划；run id 自动交回 prima，prima 评审后再派发执行。

## 单一入口流程

```text
人类
  → prima：接收需求
  → 无 run 时：派 subagent(thirteenth) 澄清意图
  → thirteenth：question → cy_templates → cy_plan
  → 自动把 run_id 交回 prima
  → prima：cy_state → cy_plan_review → subagent 派发 → cy_state(wait=true)
```

不需要手动切换 agent，也不需要复制 run id。

## 变化

- `/cybertron` 命令改为 `agent: prima`。
- `thirteenth` 改为 `mode: all`，可以作为 prima 的规划子代理被派遣；同时仍可单独选用。
- prima 在无 run 时允许预规划派发：把 thirteenth 作为 planning subagent 派出去，不要求已有 ready 节点。
- thirteenth 规划子会话保留 `question`、`cy_templates`、`cy_plan`；删除 `subagent`、`cy_ask`、`cy_plan_review`、`cy_state` 等非规划工具。
- thirteenth 调用 `cy_plan` 成功后，自动把 run id 写入父会话存储；prima 直接 `cy_state` 即可接管。
- 计划仍由内核写入和校验；`cy_plan_review` 门禁仍然生效，计划 revision 变化会重新要求评审。

## 升级

```bash
# 全局安装
cybertron init --apply
cybertron doctor --global

# 或 npm
npx -y cybertron-agents@0.7.0 init --apply
```

升级后重启 OpenCode。项目目录不需要 `.opencode`；run 账本仍在 `<project>/.cybertron/runs/`。
