# Cybertron v0.2.1

> 已发布：2026-11-15 · npm / PyPI / GitHub Release
> 上一版：[v0.2.0](https://github.com/zhiwenC125/Cybertron-agents/releases/tag/v0.2.0)

## 变更

- 新增 `CONTRIBUTING.md` 与 `RELEASE.md`，定义协作、审查与发布流程。
- 新增 `scripts/bump_version.py`，统一 npm / PyPI / Shell / Python fallback 的版本号，并在发布工作流中校验。
- 新增标签驱动的 `.github/workflows/publish.yml`：验证 tag 与 `main`、运行测试与阶段 5 验收、构建并比对 npm/wheel 内容、通过 OIDC Trusted Publishing 发布到 npm 与 PyPI，最后创建 GitHub Release。
- `main` 分支启用保护：要求 Pull Request 与 `offline` CI 通过。
- 本版本**不改变** 13 个角色、`/cybertron` 命令、插件或 Python 运行时行为。

## 安装

**npm**
```bash
npx -y cybertron-agents@0.2.1 init --apply --global
```

**pipx**
```bash
pipx install cybertron-agents==0.2.1
cybertron init --apply --global
```

**GitHub Shell**
```bash
curl -fsSL https://raw.githubusercontent.com/zhiwenC125/Cybertron-agents/v0.2.1/install.sh -o install.sh
bash install.sh --apply --global --version v0.2.1
```

## 验证

```bash
python3 -m unittest discover -s tests -q
python3 -m cybertron.stage5_verify
python3 cybertron_primes_engine.py
python3 scripts/bump_version.py 0.2.1 --check
```

发布后由 `publish.yml` 在 Release 附件中提供 npm tgz、wheel、sdist 与 `install.sh` 的 `SHA256SUMS`。

## 说明

首次由 `publish.yml` 通过 Trusted Publishing 发布；npm 与 PyPI 的 OIDC 配置需与工作流中的 owner / repo / workflow / environment 完全一致。若某渠道成功而后续渠道失败，只重跑失败的 job，不重复发布不可变版本。
