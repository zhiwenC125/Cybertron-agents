# Cybertron Agents 0.5.0

发布日期：2026-11-18

0.5.0 把计划所有权从 prima 拆到 thirteenth，给计划加上评审门禁与交接元数据，并按角色开放受控 shell。

## 亮点

- **计划与派发分离**：`thirteenth` 成为唯一计划作者，负责人类意图澄清、`cy_templates` 与 `cy_plan`；`prima` 只负责读取/接管 run、`cy_plan_review`、`cy_ask`、`subagent` 派发与 `cy_state(wait=true)` 结算。跨 session 用 `cy_state(run_id=...)` 接管。
- **计划评审门禁**：新增 `cy_plan_review` 与内核 `plan.reviewed`。评审绑定 `plan_revision` 与 `plan.json` 的 SHA-256；计划修订或 `plan.json` 被直接改动后旧评审立即失效，`subagent` 派发会被拒绝，直到 prima 重新评审。
- **交接元数据**：`cy_plan` / `cy_state` 返回 `handoff`，包含 `run_id`、`plan_revision`、`next_agent=prima`、ready 节点卡、`access_mode`、`required_gates` 与 `review_current`。
- **plan.json 定位明确**：`plan.json` 是内核写入的当前计划投影；运行时状态仍以 `events.jsonl` 为准。任何角色都不能写 `.cybertron/runs/**`，直接改 `plan.json` 会破坏评审哈希绑定。
- **权限矩阵补强**：L2 审查官可读 HAL/引脚/构建配置；QA 可写 `sim/**`、`sim.resc`、`sim.expect`；L1 与文档官可发现文件；架构师可在脚手架前读取现有源码树。
- **角色级 shell 白名单**：`vector` 只读 Git、`micronus` lint、`alchemist` test/sim、`nexus` build/工具链探测、`megatronus` 烧录/串口/回滚、`solus`/`amalgamous` 格式化与本地编译检查。`cy_check` 目标也按角色收窄。
- **插件级 shell 护栏**：白名单由 `registry.py` 编译为 `shell_policy.mjs`，OpenCode 插件在 `execute.before` 拒绝换行、链式命令、重定向、命令替换和未列入 allow/ask 的命令；宿主权限仍是最终边界。
- **DSH**：保持单 persona `Cybertron` preset 兼容模式，prima 在该 preset 内同时规划与派发；OpenCode 13 角色路径才执行 thirteenth/prima 拆分。DSH bundle 仍包含此前的加载修复。

## 安装

```bash
# npm（npx 不会安装全局 cybertron）
npx -y cybertron-agents@0.5.0 init --apply --project .
npx -y cybertron-agents@0.5.0 models setup

# pipx
pipx install cybertron-agents==0.5.0
pipx ensurepath && exec zsh
cybertron init --apply --project .

# GitHub Shell
curl -fsSL https://github.com/zhiwenC125/Cybertron-agents/releases/download/v0.5.0/install.sh -o install.sh
bash install.sh --apply --project .
./.opencode/bin/cybertron models setup --project .
```

DSH：

```bash
dsh plugin --profile desktop add "$(npx -y cybertron-agents@0.5.0 dsh path)"
```

安装后新建会话：使用 OpenCode 时先选择 `thirteenth` 规划，再用 `prima` 派发；使用 DSH 时选择 `Cybertron` preset。

## 升级说明

- 重新生成 13 个角色配置后，运行 `opencode2 debug agents` 核对角色与权限。
- 需要重启 OpenCode 以加载新插件、`shell_policy.mjs` 与角色提示词。
- DSH 需要重新安装 bundle（或重启 DSH）以应用新的 preset 文案。
- 旧 `release/v0.3.0`、`release/v0.4.0` 分支在本次发布后删除；对应 tag 与发布说明保留。
- 升级后第一次派发前必须调用 `cy_plan_review`，否则 `subagent` 会被拒绝。
