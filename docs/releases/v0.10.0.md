# Cybertron Agents 0.10.0

## OpenCode 任务编排

- 有现成回归测试的单文件修复默认安排一个实现节点。内核为同一输入执行一次固定检查，并保存命令退出码、输出摘要和输入摘要。
- 风险按整个任务的实际改动计算。写入范围互不冲突的独立节点可以并行。跨模块改动需要独立审查和验收，两者直接使用现有检查回执。
- 检查失败时，依赖它的节点等待，无关节点仍可推进。局部修订后复用输入仍有效的检查回执。
- 项目内写入任务生成 `.cybertron/runs/<运行目录>/plan.md`，展示依赖、状态、验证和下一步。模型响应或等待中断时，运行账本记录中断位置，Prima 可接续已保存的 run。

## 隔离软件命令

实现、测试、构建和静态检查角色按各自命令清单，通过 `cy_shell` 在临时项目副本里执行获准命令。每次调用保留输入摘要和实际退出码。项目外写入、物理设备操作和远程部署继续使用各自的专项审批。

## 升级与验收

使用 [安装与升级指南](../packaging-and-installation.md) 更新并重新加载 OpenCode。以 Prima 打开临时项目，用 [自然语言验收用例](../testing/opencode-acceptance.md) 试用。

真实 OpenCode 会话验证了单文件修复和跨模块并行交付。宿主桥配合真实沙箱工具验证了检查失败后的局部修复与回执复用。固定隔离检查依赖 macOS 的 `sandbox-exec`。
