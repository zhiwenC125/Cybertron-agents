# Cybertron Agents 0.4.0

发布日期：2026-11-18

0.4.0 把权限词汇收敛到宿主原生模型，修复 DSH 加载路径，并让安装入口与 run 目录更直接。

## 亮点

- **宿主原生访问模式**：run 级 `access_mode` 使用 `read-only`、`workspace-write`、`danger-full-access`，与 DeepSeek Harness 的 `SandboxMode` 一致；OpenCode 侧翻译为原生 `edit` / `external_directory` 权限规则。
- **DSH 可用性修复**：`Cybertron` preset 不再从 profile 解析 `@deepseek-ai/dsh-tools`，并自动从 bundle 同级的 `cybertron-runtime` 或源码目录解析 Python 内核。preset 名称由 `Cybertron v6` 改为 `Cybertron`。
- **可读 run 目录**：`.cybertron/runs/<english-slug>/`，不再拼接 ID；`run_id` 保存在 `run.json` 和事件中。旧 UUID 目录继续可读。旧 `SessionStore` 新会话同样使用纯 slug 目录。
- **安装入口修复**：README 区分 `npx`、npm 全局、pipx、pip 和 Shell 启动器，补充 `pipx ensurepath`、绝对路径与 `python3 -m cybertron.installer` 兜底；`bin/cybertron.mjs` 与 `install.sh` 补上可执行位。
- **提问走原生卡片**：`cy_ask` 通过宿主审批卡记录 `approval.granted`；原生 `question` 工具会记录问题与答案。
- **稳定性与性能**：跳过 UNIX socket/FIFO、不可读文件与常见依赖/缓存目录；用户手动切换的模型优先于配置默认值。
- **README**：置顶壁纸更新为 Cybertron Agents 主视觉。

## 安装

```bash
# npm（npx 不会安装全局 cybertron）
npx -y cybertron-agents@0.4.0 init --apply --project .
npx -y cybertron-agents@0.4.0 models setup

# pipx
pipx install cybertron-agents==0.4.0
pipx ensurepath && exec zsh
cybertron init --apply --project .

# GitHub Shell（不修改 PATH，使用打印出的绝对路径）
curl -fsSL https://github.com/zhiwenC125/Cybertron-agents/releases/download/v0.4.0/install.sh -o install.sh
bash install.sh --apply --project .
./.opencode/bin/cybertron models setup --project .
```

DSH：

```bash
# npm
dsh plugin --profile desktop add "$(npx -y cybertron-agents@0.4.0 dsh path)"
# pipx / Shell
dsh plugin --profile desktop add "$(cybertron dsh path)"
```

安装后新建会话，选择 `Cybertron` preset；旧 preset 名称会随 bundle 重装更新。

## 升级说明

- 角色权限与配置由安装器重新生成；升级后运行 `opencode2 debug agents` 核对 13 个角色。
- 需要重启 OpenCode 以加载新插件与禁用旧全局插件。
- DSH 需要重新安装 bundle（或重启 DSH）以应用新的 preset 名称与加载修复。
- 旧 `.cybertron/runs/<uuid>` 与 `.cybertron/sessions/<uuid>` 不迁移；新目录才使用纯 slug。
