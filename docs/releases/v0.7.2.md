# Cybertron Agents 0.7.2

发布日期：2026-11-18

0.7.2 修复 0.7.1 的一个阻塞问题：`cy_plan` 的节点 schema 没有声明 `external_scope`，且 `additionalProperties: false`，模型无法把项目外路径传进计划，功能在 OpenCode UI 里实际不可用。

## 修复

- `cy_plan` 的 `node` / `nodes` schema 增加 `external_scope`（字符串数组）。
- `cy_plan` 描述与 thirteenth 的系统提示改为：`workspace-write` 下用 `external_scope` 声明具体的外部文件，每次写入由宿主权限卡批准；只有用户明确要求整片外部访问时才用 `danger-full-access`。
- 新增静态契约测试，确保插件源码与生成副本都暴露该字段。

## 兼容性

- 已发布的 0.7.1 计划若包含 `external_scope`，0.7.2 读取方式不变；旧 run 无需迁移。
- DSH 适配器本来就接受原始 JSON payload，不受此 schema 限制。

## 升级

```bash
# 全局安装
cybertron init --apply
cybertron doctor --global

# 或 npm
npx -y cybertron-agents@0.7.2 init --apply
```

升级后重启 OpenCode。
